## Security control artwork

The README uses original project artwork served by the following official sources. OWASP CRS identifies the ModSecurity / CRS combination. DLP, independent authorization, and runtime monitoring use the local original red/charcoal pictograms, since these are control roles rather than specific brands.

| Control | Original artwork | Brand information |
| --- | --- | --- |
| modsecurity-crs | [Original image](https://owasp.org/www-project-modsecurity-core-rule-set/assets/images/logo.png) | [Project source](https://owasp.org/www-project-modsecurity-core-rule-set/) |
| suricata | [Original image](https://suricata.io/wp-content/uploads/2023/09/Logo-Suricata-horiz-R.png) | [Project source](https://suricata.io/branding-images/) |

The official image files are linked remotely because direct downloads were unavailable during packaging. To vendor them locally, run `python3 assets/logos/download_official_logos.py` from the repository after obtaining any required trademark permissions. The script downloads the four files and switches the README to local paths only after successful downloads. No logo colors or proportions are changed. All marks remain the property of their respective owners; their use does not imply endorsement. Suricata's branding page specifically requests permission for use of its name or logo.
